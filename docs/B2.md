# Lưu bài trên Backblaze B2

MintMath lưu và mở bài trên **tài khoản Backblaze B2 của chính người dùng**. Mỗi người tự tạo tài khoản, bucket và khóa, rồi nhập vào app. Không có máy chủ MintMath nào đứng giữa: app gọi thẳng API tương thích S3 của B2.

Chức năng này chạy trên cả ba dạng app:

| Dạng app | Cách gọi B2 | Cần cấu hình CORS? |
| --- | --- | --- |
| Bản web / PWA | `fetch` của trình duyệt | **Có**, cho đúng địa chỉ của trang (bước 4) |
| App máy tính (.dmg, .exe) | HTTP native của Tauri (`@tauri-apps/plugin-http`) | Không |
| App Android (.apk) | HTTP native của Capacitor (`CapacitorHttp`) | Không |

## 1. Tạo tài khoản và bucket

1. Đăng ký tại https://www.backblaze.com/cloud-storage. 10 GB đầu tiên miễn phí; xem lại bảng giá hiện tại trước khi dùng nhiều.
2. Vào **Buckets → Create a Bucket**:
   - Bucket name: tên duy nhất trên toàn B2, ví dụ `mintmath-ten-ban`.
   - Files in Bucket are: **Private**.
3. Trên trang bucket, ghi lại dòng **Endpoint**, dạng `s3.us-west-004.backblazeb2.com`.

## 2. Tạo application key (khóa riêng cho MintMath)

**Application Keys → Add a New Application Key**:

- Name of Key: `mintmath`
- Allow access to Bucket(s): **chỉ bucket vừa tạo**
- Type of Access: **Read and Write**
- (Không bắt buộc) File name prefix: `mintmath/`

Sau khi tạo, chép **keyID** và **applicationKey**. applicationKey **chỉ hiện một lần**.

Không dùng Master Application Key, và không chia sẻ applicationKey cho người khác.

## 3. Kết nối trong app

Bấm **☁ Kết nối Backblaze B2** (trên thanh công cụ, hoặc vào Thư viện → tab ☁ Backblaze B2), rồi nhập:

- keyID, applicationKey
- Tên bucket
- Endpoint (ví dụ `s3.us-west-004.backblazeb2.com`)
- Thư mục trong bucket (mặc định `mintmath/`)

App thử kết nối trước, chỉ lưu thông tin khi kết nối thành công. Khóa được lưu **trên thiết bị đó**: trong bộ nhớ của trình duyệt (bản web/PWA) hoặc dữ liệu của app (desktop, Android). Mỗi máy kết nối một lần. **Ngắt kết nối B2** sẽ xóa khóa khỏi máy, còn dữ liệu trên B2 vẫn giữ nguyên.

## 4. CORS cho bản web / PWA

Trình duyệt chỉ cho trang web gọi B2 nếu bucket có quy tắc CORS cho **đúng địa chỉ của trang**. Ví dụ: `https://papts0909.github.io`, tên miền riêng như `https://monglinhnguyendat.id.vn`, hay `http://localhost:4173` khi chạy `vite preview` trên máy.

Khi thiếu quy tắc, app báo *"Bucket … chưa cho phép trang … truy cập"* và hiện thẻ **Bật truy cập cho bản web (làm một lần)**. Thẻ hướng dẫn lấy Master Application Key, rồi đưa một lệnh đã điền sẵn tên bucket và địa chỉ trang, kèm nút Chép:

- macOS / Linux (Terminal, hoặc Google Cloud Shell): `curl -fsSL <app>/b2-cors.sh | sh -s -- <bucket> <địa chỉ>`. Chỉ dùng `sh`, `curl`, `grep`, `sed`.
- Windows (PowerShell 5.1 có sẵn): tải `<app>/b2-cors.ps1` rồi chạy với `-Bucket` và `-Origin`.

Hai script nằm ở `frontend/scripts/` và được build ra gốc của app. Script hỏi khóa trong Terminal, không lưu khóa, và đưa khóa cho `curl` qua tệp cấu hình tạm chứ không qua dòng lệnh. Bản `.sh` thay toàn bộ quy tắc CORS của bucket bằng quy tắc `mintmath-web` và báo trước nếu bucket có quy tắc khác. Bản `.ps1` giữ các quy tắc khác.

Không thể bật từ chính trang web: Backblaze từ chối các lệnh đổi cài đặt bucket (`b2_list_buckets`, `b2_update_bucket`) gọi từ trình duyệt.

Nếu app báo *"Không tới được … chặn Backblaze"* thì lỗi không phải do CORS: mạng (ví dụ tường lửa công ty) đang chặn B2.

**Mẫu CORS trên trang web Backblaze là không đủ.** Mẫu đó chỉ cho phép tải xuống (GET/HEAD), không cho các header ký request mà MintMath gửi, nên app vẫn bị chặn khi liệt kê và lưu file.

Các cách dưới đây dành cho người quản lý bản triển khai.

### Cách không cần máy tính: chạy trên GitHub Actions

Miễn phí với repo public. Không cần Node hay Terminal.

1. **Lưu khóa vào Secrets** (một lần): repo trên GitHub → **Settings → Secrets and variables → Actions → New repository secret**, tạo hai secret:
   - `B2_KEY_ID`: keyID của **Master Application Key** (hoặc khóa có quyền `listBuckets` + `writeBuckets`).
   - `B2_APP_KEY`: applicationKey tương ứng.

   GitHub che giá trị secret, không hiện trong log, kể cả khi repo public.
2. **Chạy:** tab **Actions → Set B2 CORS → Run workflow**, nhập:
   - **Tên bucket**.
   - **Địa chỉ web**: mặc định đã có `https://monglinhnguyendat.id.vn https://papts0909.github.io`.
3. Lần chạy hiện ✔ xanh, và log có dòng `✔ Đã đặt CORS cho bucket …`, là xong. Tải lại trang MintMath rồi bấm **Kết nối**.

Lưu ý: repo public thì ai cũng xem được log của workflow. Log có tên bucket và các địa chỉ web, nhưng không có khóa.

### Cách dễ nhất: script có sẵn (chỉ cần Node, không cài thêm gì)

Chạy trên máy có Node 18 trở lên, trong thư mục `frontend` của repo:

```bash
node scripts/b2-cors.mjs
```

Script hỏi lần lượt:
- **keyID / applicationKey có quyền sửa bucket**: dùng **Master Application Key** (Account → Application Keys), hoặc một khóa có quyền `listBuckets` + `writeBuckets`. Khóa giới hạn mà bạn dùng trong app thường **không** có quyền này.
- **Tên bucket**.
- **Địa chỉ web của MintMath**: điền địa chỉ app báo, ví dụ `monglinhnguyendat.id.vn`. Script luôn thêm sẵn `https://papts0909.github.io`, `http://localhost:4173` và `http://localhost:5173`.

Script giữ nguyên các quy tắc CORS khác của bucket, chỉ thêm hoặc thay quy tắc tên `mintmath-web`. Muốn chạy không cần hỏi:

```bash
node scripts/b2-cors.mjs --bucket ten-bucket --origin https://monglinhnguyendat.id.vn --key-id KEYID --app-key APPKEY
```

Chạy ở máy nào cũng được, vì script sửa cấu hình của **bucket** chứ không sửa máy. Chạy xong, tải lại trang MintMath rồi bấm **Kết nối**.

### Cách khác: B2 CLI

```bash
pip install b2
```
```bash
b2 account authorize
```
```bash
b2 bucket update ten-bucket allPrivate --cors-rules '[
  {
    "corsRuleName": "mintmath-web",
    "allowedOrigins": ["https://monglinhnguyendat.id.vn", "https://papts0909.github.io", "http://localhost:4173"],
    "allowedOperations": ["s3_get", "s3_head", "s3_put", "s3_delete"],
    "allowedHeaders": ["*"],
    "exposeHeaders": ["ETag"],
    "maxAgeSeconds": 3600
  }
]'
```

Lệnh `b2 bucket update` **thay toàn bộ** quy tắc CORS cũ của bucket.

## 5. Dùng

| Nút | Làm gì |
| --- | --- |
| **☁ Lưu lên B2** / Ctrl+S | Lưu bài đang mở thành `mintmath/<tiêu-đề>__<id>.mintmath.json`. Nếu đổi tiêu đề, tệp cũ được thay bằng tệp mới. |
| **⇅ Đồng bộ thư viện** | Đưa bài mới hoặc đã sửa từ máy lên B2 và từ B2 về máy. Không bao giờ xóa. Nếu một bài bị sửa ở cả hai nơi, giữ cả hai: bản trên B2 được lưu thành "… (bản trên B2)". |
| Bấm vào một bài trong tab ☁ | Mở bài đó (bài đang mở được giữ lại trong Thư viện). |
| **Tải tệp lên** | Đưa bất kỳ tệp nào vào thư mục MintMath trên B2. |
| **⬆ B2** (trong nhóm Xuất) | Lưu bản `.tex` và PDF của bài đang mở lên B2. |
| ⤵ / ⬇ / 🗑 với tệp khác | Nhập `.tex` thành bài, tải tệp về, xóa trên B2. |

Xóa một bài trên B2 không xóa bài đó trong Thư viện trên máy. Lần đồng bộ sau, bài sẽ được đưa lên lại; muốn bỏ hẳn thì xóa ở cả hai nơi.

## Ghi chú kỹ thuật

- API: S3-compatible (ListObjectsV2, GetObject, PutObject, DeleteObject), ký SigV4 bằng `aws4fetch`. Code ở `frontend/src/cloud/`.
- Trạng thái đồng bộ (ETag và thời điểm sửa đã đồng bộ của từng bài) lưu trên máy dưới khóa `mathpad.b2.sync.v1`, dùng để biết bên nào đã đổi.
- Script CORS: `frontend/scripts/b2-cors.mjs` (API native của B2: `b2_authorize_account`, `b2_list_buckets`, `b2_update_bucket`), có test ở `frontend/tests/b2Cors.test.ts`.
- Test: `frontend/tests/b2.test.ts` (ký request, đọc danh sách, báo lỗi, logic đồng bộ) và `frontend/e2e/b2.spec.ts` (B2 giả lập: kết nối, sai khóa, lưu, đổi tên, mở trên máy khác, đồng bộ, xung đột, tệp khác, ngắt kết nối).
- Chưa được thử với tài khoản B2 thật trong môi trường phát triển.
